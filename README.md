# 离线滤镜的三维 LUT 双向张量与安全色域接合

这里的线性色域调色表和像素块是用于设备联调的合成资料。使用 Node.js 22。运行 `npm ci --offline` 核对依赖锁，`npm run inspect` 查看资料字段，`npm test` 检查资料格式及相互引用。检视脚本只读取元数据。

## 数据格式

LUT 每轴均匀 size 个点。RGB 输入以候选资产自身线性域 [0,1]^3 为准，每个体素采用从 (0,0,0) 到 (1,1,1) 的共同对角线，按 x,y,z 分量的六种次序拉出六个四面体。在面上按同一几何点去重，不将两次表示视作逆向多解。共享面上各顶点在 epsilon 内相等才可由相邻单元共同发布。必须区分超出目标体并无解、多个不相连的输入、以及有正维数的一族输入。唯一解的空间容差为 inverseTol。典型十万像素请求以 readBudget 记确需解码的单元次数，以 pivotBudget 记独立求解的四面体次数。设备内缓存、索引及临时输出计 workBytes，原 LUT 数据拥有者的只读字节不计。 每个像素块 256 点，三种表由 colorVertex 分别提供。历史预览的查证不要求完整表全部常驻，保留足够的资产标识和实际交付值。调色包从线性 RGB 入参到线性 RGB，调用端自行处理显示编码，不准把编码色直接套入。

## 取数

`inputs/lut-assets.json` 保存标定、规格和调用记录。记录中的范围除明确说明外从零开始，使用半开区间。批量数组按调用记录列出的顺序交付。colorVertex(i,j,k,variant) 给表的顶点，colorPixels(tile) 给连续 256 个 RGB 点。
